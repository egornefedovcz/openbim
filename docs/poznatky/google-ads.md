# Google Ads API – hledanost na Googlu

*❓ Neověřeno – čeká na developer token*

Postup žádosti: účet správce (MCC) → Nástroje → Nastavení → Centrum API → developer token, typ Basic, účel „interní analýza klíčových slov (Keyword Planner)“. Schválení obvykle několik dní.

Očekávání (ověřit): `KeywordPlanIdeaService.GenerateKeywordHistoricalMetrics` vrací průměrnou měsíční hledanost a 12 měsíců; přesná čísla jen pro účty s reklamní útratou, jinak rozmezí.
