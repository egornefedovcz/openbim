# Pozice na Seznamu

*2026-10-21 – ❌ nejde*

`https://search.seznam.cz/robots.txt` pro `User-Agent: *` obsahuje `Disallow: /` (povolená je jen titulní stránka a pár formulářů). Výjimka `Allow: /*?q=` platí jen pro Googlebota.
→ Automatické stahování výsledků Seznamu nedělat.

Otevřené: zjistit, zda Seznam Webmaster (webmaster.seznam.cz) nabízí statistiku dotazů / pozic pro vlastní web a zda má API. ❓
